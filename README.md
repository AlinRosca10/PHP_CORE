# 🧩 Decision Project

Un proiect PHP demonstrativ pentru luarea deciziilor — include structuri condiționale, exemple practice și comparații între versiuni PHP.

---

## 🚀 Funcționalități

- Demonstrații pentru `if`, `else`, `elseif`, `switch`
- Exemple cu operatori ternari și comparații stricte
- Exemple de diferențe PHP 7 vs PHP 8

---

## ⚙️ Instalare

1. Clonează repository-ul:
   ```bash
   git clone git@github.com:alinrosca/PHP_CORE.git
2. Intră în director:

   cd decision_project
3. Rulează proiectul local cu XAMPP sau PHP built-in:

   php -S localhost:8888
